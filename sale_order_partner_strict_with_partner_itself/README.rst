================================================================
Strict domain filters for partners on sale, with customer itself
================================================================

* Only allow correct type and parent for addresses, as well as the main
  customer itself
* On the sale order form, ``Invoicing Address`` and ``Shipping Address``
  only show the customer itself, or contacts that are its direct children
  with a matching address type (``invoice``/``delivery``) — not the full
  contact database
