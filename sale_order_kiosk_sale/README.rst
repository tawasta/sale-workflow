====================
Simulate Kiosk sales
====================

::

    Process delivery and invoice of a sale with one button, then print receipt

Configuration
=============
::

    Have one cash Journal enabled.

Usage
=====
::

    Go to a sale and click on "Kiosk sale done" to Confirm the sale, set delivery
    as Done, create an invoice and post it, and set invoice as paid. This all is
    done with one button. A user is directed to invoice form view where he/she
    can print the receipt of an invoice.

Known issues / Roadmap
======================
::

    Note how the payment is done.
