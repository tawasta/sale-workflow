================================================================
Sale Order: Create Regular Invoice and Bypass the Invoice Wizard
================================================================

* Adds a new "Create Regular Invoice" button to Sale Order form 
  that bypasses the invoice type selection (regular vs downpayment)
  for a faster regular invoice creation.

Configuration
=============
* Optionally, in Sale Configuration, check the 
  "Hide standard 'Create Invoice' button" checkbox to hide the
  core invoice wizard launching button altogether

Usage
=====
* Just create and confirm a SO to see the new button
