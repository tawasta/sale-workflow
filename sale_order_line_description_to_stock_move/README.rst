=============================================
Sale Order: SO Line Description to Stock Move
=============================================

* Description field of sale order line is moved to a created
  description_picking field of stock.move
* The product name at the start of the sale order line description is
  trimmed out

Configuration
=============
* None needed

Usage
=====
* Confirm a sale and view its delivery order
