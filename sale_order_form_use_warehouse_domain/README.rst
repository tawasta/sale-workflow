====================================================
Sale Order – Warehouse usability domain in form view
====================================================

::

    Warehouse usability domain in Sale Order form view. This module is meant
    to hide chosen warehouses in the view, but without Record rules.

Configuration
=============
::

    sale_stock -module needs to be installed.

Usage
=====
::

    Go to a warehouse form view and select is_usable_warehouse -field as True.

Known issues / Roadmap
======================
::

    This module modifies sale order form view domain.
