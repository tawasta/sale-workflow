===================================================
Puts the limit to sale order names to 13 characters
===================================================

Editing of sale order names is enable with the dependency of this
module, sale_order_edit_order_name_in_quotation. This module limits
the written name to 13 characters and longer names raises a message
to a user.

Configuration
=============
No special configuration is required

Usage
=====
Go to Apps to install this module

Known issues / Roadmap
======================
write -function limits the name length. So a message is always shown
when a name is edited.
