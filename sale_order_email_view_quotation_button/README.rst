======================================
Sale Order Email View Quotation Button
======================================

* The button of a quotation email that would read "Accept & Sign Quotation"
  reads "View Quotation" instead.
* The button still opens the quotation in the portal, where the customer
  accepts and signs it.
* The other button labels of sale order emails are not changed.

Configuration
=============
\-

Usage
=====
* Send a quotation that requires an online signature by email. The button of
  the email reads "View Quotation".
