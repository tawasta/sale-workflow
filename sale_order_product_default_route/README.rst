=================================================
Get default Route from product to Sale order line
=================================================

Use default route set on a product to add it to Sale Order line.
This module is used to force a route used on a product.

Configuration
=============
None needed

Usage
=====
Go to Routes and select "Use this on Sale Order line" for a route.
Select the route to be used on a product. Make a sale with the product
and this route it set to the sale order line.

Known issues / Roadmap
======================
This module modifies the default behaviour of routes.
Use it if you know what you are doing.
