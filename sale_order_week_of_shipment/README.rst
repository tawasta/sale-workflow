=============================
Sale Order - Week of Shipment
=============================

* Adds week of shipment value to sale order
* Shows this info in sale order PDF print

Installation
============
* Just install the module

Configuration
=============
* No configuration needed

Usage
=====
Set the default week of shipment in sales settings.
Check how Delivery Date on a sale order changes when
the week of shipment is changed on the sale order.
Additional weeks are applied from settings.
