===============================================
Force Sale orders to be set as invoiced en mass
===============================================

* Select multiple sale orders and force them as invoiced

Configuration
=============
None needed

Usage
=====
Go to Sale Orders list view and select several of them. Then click "Force sale order to be invoiced"
under Actions -dropdown selection. After that click "Force invoiced".
