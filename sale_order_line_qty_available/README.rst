=============================
Sale Order Line Qty Available
=============================
::

    Show qty_available on sale order line list view and in sale order form view

Configuration
=============
::

    Sale module needs to be installed

Usage
=====
::

    Select a sale order and check the available quantities of its products

Known issues / Roadmap
======================
::

    Be wary of duplicate technical field name definitions.
