=================================================
Enable to edit Sale Order name in Quotation state
=================================================

The main purpose of this module is to enable editing a name of sale orders, which
are in quotation status. The name information flows to pickings and invoices, and
this is a wanted behaviour. But always ask from an Odoo installation user if this
is always wanted!

Choosing an already existing sale order name is prevented with onchange.

Configuration
=============
No special configuration is required

Usage
=====
Install this module and edit a name of a sale order in quotation status

Known issues / Roadmap
======================
There should not be any issues which appear in the use of this module, since
editing is only enabled for sale orders which are in quotation status.

A developer could check how this module behaves in versions after 17.
